# Отчёт по учебной практике, вариант 13

ООО «Вектор-Опт» (учебная организация), ОКВЭД 46.90.
Тема: система поддержки выбора поставщика и планирования закупок.

## Что где лежит

| Папка | Содержимое |
| ----- | ---------- |
| `bpmn/` | модели BPMN и сборщик `build_models.py` |
| `db/` | схема базы, генератор наполнения, запросы, рисователи ER и DFD |
| `calc/` | инженерный расчёт мощности и тепловыделения |
| `img/` | рисунки для отчёта |
| `docs/` | черновики разделов и собранные источники |
| `src/` | программный компонент (раздел 3) |

## Как пересобрать

```
python3 bpmn/build_models.py                 # схемы BPMN
createdb vektor_opt
psql -d vektor_opt -f db/01_schema.sql
python3 db/gen_data.py && psql -d vektor_opt -f db/02_data.sql
psql -d vektor_opt -f db/03_queries.sql > db/queries.log
python3 db/er.py && python3 db/dfd.py        # ER и DFD
python3 calc/power.py                        # инженерный расчёт
```

Наполнение базы генерируется с фиксированным seed, поэтому числа в отчёте
воспроизводятся при повторном прогоне.
